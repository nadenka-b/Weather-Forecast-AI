# Frontend (Chainlit / Gradio)

UI реализуется на **Этапе 15**. По заданию MLF-2026 Streamlit не рекомендуется —
используйте **Chainlit** или **Gradio** (стриминг ответов агентов, дерево рассуждений,
кнопки HITL, асинхронный бэкенд).

План страниц:

- вход / регистрация (JWT);
- загрузка метеоряда (CSV) + выбор города, целевой переменной (`mean_temp` / `precipitation`)
  и горизонта (7–14 дней);
- статус задачи и результат: график факт/прогноз, метрики, выбранная модель и гиперпараметры;
- HITL-очередь: подтверждение прогнозов для экстремальных погодных кейсов;
- оценка качества: сравнение режимов (`baseline` / `+rag` / `+agents` / `+foundation`), графики Plotly;
- логи рассуждений агентов и LLM-вызовов (дерево reasoning_logs).

> Методичка Step_12 описывает Streamlit-вариант из другого курса — используйте её как
> технический ориентир (структура страниц, Docker), но реализуйте UI на Chainlit/Gradio.
