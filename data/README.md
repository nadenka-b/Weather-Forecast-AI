# Данные

Каталоги создаются скриптом `scripts/download_data.py` (Этап 9, методичка Step_6):

- `raw/` — исходные датасеты (не коммитятся):
  - Jena Climate (10-минутные метеонаблюдения, 2009–2016, ~14 признаков);
  - `sumanthvrao/daily-climate-time-series-data` (дневные данные, Дели);
  - наборы Monash Time Series (раздел weather);
- `processed/` — очищенные ряды и тестовый набор (не коммитятся);
- кэш эмбеддингов/моделей — `data/cache/`.

В отчёте для каждого датасета указывается число признаков (минимум 5; при нехватке
добавляются лаги, скользящие статистики, календарные признаки).
